Investigación técnica

JavaScript (Vanilla)

JavaScript es el lenguaje de programación de la web: agrega comportamiento a las páginas. HTML define la estructura, CSS el aspecto y JS la lógica y la interacción.

  • Variables: guardan datos (let, const).
  • Funciones: bloques de código reutilizables.
  • Eventos: reacciones a acciones del usuario (clic, envío, teclado).
const tarifa = 5;                         // variable
function costo(kg){ return kg * tarifa; } // función
btn.addEventListener("click", () => {     // evento
  alert("Costo: $" + costo(3));
});

jQuery

Librería creada por John Resig en 2006 para simplificar el manejo del DOM, los eventos y las animaciones, y resolver diferencias entre navegadores. Su sintaxis usa el símbolo $: $("selector").acción().

Tarea JavaScript vanilla jQuery
Seleccionar document.querySelector(".a") $(".a")
Ocultar el.style.display="none" $(".a").hide()
Evento el.addEventListener("click",f) $(".a").click(f)
Animar CSS / Web Animations $(".a").slideToggle()

Ventajas: código corto, efectos listos, AJAX sencillo. Desventaja: carga una librería extra que hoy muchas veces no es necesaria.

JSON

JavaScript Object Notation es un formato de texto ligero para intercambiar datos, basado en pares clave-valor. Es el estándar de las APIs web porque cualquier lenguaje puede leerlo.

{
  "guia": "VX-1024",
  "cliente": "Ana López",
  "estado": "En tránsito",
  "peso_kg": 2.5,
  "urgente": true,
  "etapas": ["Recolectado", "En ruta"]
}

Las APIs se consumen con fetch(url).then(r => r.json()). Este proyecto usa JSON para enviar datos al webhook de Discord y al correo.

Web hosting y dominios

Un servidor es una computadora siempre encendida que entrega archivos web. El hosting es el servicio que alquila ese espacio.

Vercel despliega sitios estáticos desde GitHub: cada git push genera una nueva versión publicada en una red global (CDN) con HTTPS automático.

Un dominio es la dirección legible (veloz.com); el DNS la traduce a una IP. Un TLD es la terminación: .com, .org, .sv (país). La propagación DNS es el tiempo (de minutos a 48 h) que tardan los servidores del mundo en enterarse de un cambio.
