## 3. Integraciones Especiales
### 💬 Formulario de Contacto + Webhook de Discord + Correo
1. El usuario completa el formulario en la web.
2. `js/main.js` ejecuta dos peticiones asíncronas (`fetch`) en paralelo: una al Webhook de Discord y otra a FormSubmit, que reenvía el mensaje al correo de la empresa.
3. La notificación aparece en Discord y el correo llega a la bandeja de la empresa.

### 🌐 Idioma y modo oscuro
* Botón **EN/ES**: traduce todo el sitio (`js/i18n.js`) y guarda la preferencia.
* Botón **🌙/☀️**: alterna entre modo claro y oscuro usando `data-bs-theme` de Bootstrap 5.3.
